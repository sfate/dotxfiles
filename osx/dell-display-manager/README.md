# Dell Display and Peripheral Manager

`U3223QE.json` is an exported settings file for Dell Display and Peripheral Manager for macOS (DDPM). It contains settings for the Dell U3223QE monitor.

## Import the settings

1. Install and open **Dell Display and Peripheral Manager** for macOS.
2. Connect the U3223QE monitor and select it in DDPM.
3. Open **Main Menu → Others → Import/Export application settings**.
4. Choose **Import**, then select `U3223QE.json` from this directory.
5. Allow DDPM to restart if prompted.

DDPM imports settings for connected monitors of the same model. This file is an application import/export file; it is not loaded automatically by macOS or by symlinking it into your home directory.
